# Anthropic Claude Code

Anthropic 的 agentic 编码系统，能读取代码库、跨文件修改、运行测试并交付已提交的代码。

## 核心能力

- **自然语言建软件** — "描述你想构建的东西，Claude Code 搞定剩下的"
- **深度代码库理解** — 搜索目录构建上下文，理解模块连接
- **跨文件编辑** — 构建新功能或执行多文件重构
- **CLI 工具自主使用** — 原生使用 git、Kubernetes、GitHub CLI 等
- **自动修复测试** — 读取错误、修复代码、重新运行直到通过
- **CI 监控** — 自动监控 GitHub/GitLab CI 并提交修复

## 企业级能力

- **零配置部署** — 企业二进制文件，一次配置全公司可用
- **安全设计** — 内置分类器区分安全与风险操作
- **自主级别控制** — 从逐条审批到自动执行
